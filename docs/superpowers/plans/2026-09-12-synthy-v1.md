# Synthy v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Local web app + CLI that converts a piano score PDF/image into a two-track MIDI via Audiveris with measure normalization.

**Architecture:** Straight pipeline of small modules (render -> engine -> score -> normalize -> midi) orchestrated by `pipeline.py`; FastAPI wrapper runs it in a thread and serves a single static page. Engine behind a Protocol.

**Tech Stack:** Python 3.11 (conda env `omr`), music21, mido, pymupdf, FastAPI, uvicorn, pytest. Audiveris 5.11 at `~/.local/opt/audiveris/bin/Audiveris`.

**Spec:** `docs/superpowers/specs/2026-09-12-synthy-design.md`

## Global Constraints

- Python >= 3.11. Run everything with `source ~/miniforge3/etc/profile.d/conda.sh && conda activate omr`.
- All durations/onsets are `fractions.Fraction` in quarter notes until MIDI ticks are computed.
- Staff 1 = right hand, staff 2 = left hand, everywhere.
- Tests never require Audiveris except `tests/test_integration.py` (skips when absent).
